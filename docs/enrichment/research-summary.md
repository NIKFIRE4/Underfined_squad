Собрал рецепты, как за одну ночь обогатить 44 199 ИНН. Основа — массовые выгрузки ФНС: реестр МСП, численность, уплаченные налоги, недоимки и правонарушения. Это ZIP-архивы с XML, их скачивают один раз. Таймаут ставьте от 300 с и включайте докачку: file.nalog.ru у вас уже не ответил. По моей оценке, выгрузки покроют около 80% признаков без единого поштучного запроса.

Поштучно стоит запрашивать только ГИР БО (бухотчётность). Это 2 запроса на ИНН, на ~40 тыс. юрлиц уйдёт около 11 часов при 2 запросах в секунду. Для ИП отчётности там нет, их пропускайте. Пустой ответ для 7707049388 почти наверняка значит, что запрос отсеяли как робота. Нужны браузерные заголовки и предварительный GET / для получения cookies. Код с рецептом есть в отчёте.

Карточка «Прозрачного бизнеса» — запасной вариант для юрлиц не из МСП. Её ограничивает капча, порог которой нигде не опубликован. Федресурс работает с заголовком Referer, его стоит запрашивать только для финалистов рейтинга. Файлы ГИСП (ПП 719) и экспорт реестра ПО Минцифры придётся скачать вручную из браузера.

За ночь без подготовки не получится:

ЕИС: FTP закрыт с 01.01.2025, теперь нужен токен через ЕСИА.
КАД: cookies генерирует JavaScript, без headless-браузера сайт отвечает 403 или 451.
ФССП: я его не исследовал. Замена — флаг «Прозрачного бизнеса» о долге у приставов больше 1000 ₽ и выгрузка недоимок.

Из аккаунтов стоит завести, если разрешат организаторы, только DaData (10 000 запросов в день бесплатно) и Checko (100 в сутки, для точечной проверки арбитражных дел).

Что проверить на одном ответе:

ГИР БО: подтверждён только ключ выручки current2110. Ключи прибыли, капитала и активов я вывел по аналогии.
«Прозрачный бизнес»: имена полей карточки взяты из коммерческих обёрток, сырые ключи могут отличаться.

Размеры архивов и имена файлов части наборов ФНС тоже не проверены.
