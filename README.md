# Undefined squad

Проект хакатона: подбор поставщиков по извещениям о закупках и позициям ТРУ.

- `01_eda_preprocessing.ipynb` — исследование и подготовка датасетов.
- `web-service/` — локальный веб-сервис: загрузка двух CSV в одну область, проверка данных, обработка и выдача файла «Поставщики».
- `tz.html` и презентация — материалы задания.

## Запуск интерфейса

Нужен Python 3.10 или новее. Сторонние пакеты для текущего MVP не требуются.

В Windows откройте `web-service/run.bat` и перейдите на http://127.0.0.1:8000.

Или из корня репозитория:

```sh
cd web-service
python server.py
```

На Linux/macOS при необходимости используйте `python3 server.py`.

Выберите «Извещения» и «ТРУ» одновременно или перетащите оба CSV в общую область. Типы определяются по столбцам, порядок и названия файлов не важны. Для короткой демонстрации есть кнопка «Подставить пример».

Сейчас работает **деморежим с вымышленными компаниями**. Реальная рекомендательная модель и поиск по открытым источникам подключаются через адаптеры в `web-service/integrations/`.

- [Инструкция по сервису и ограничения MVP](web-service/README.md)
- [Контракты подключения модели и обогащения](web-service/INTEGRATION.md)
- [Результаты проверок](web-service/VERIFICATION.md)

Загруженные датасеты, результаты обработки и временные базы остаются локально. В репозитории находятся только два небольших синтетических CSV для проверки сценария.
