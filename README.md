# Undefined squad

Проект хакатона RLT: подбор поставщиков по извещениям о закупках и позициям ТРУ.

- `web-service/` — локальный веб-сервис (монолит): интерфейс, загрузка CSV, обработка, выдача «Поставщики», эндпоинт модели.
- `recsys/` — модель ранжирования поставщиков; подключается в веб-сервис импортом.
- `enrichment/` — обогащение контрагентов по ИНН (ФНС, ЕИС, реестры), см. [docs/enrichment/README.md](docs/enrichment/README.md).
- `models/` — обученная модель и артефакты (бинарные файлы — через Git LFS).
- `01_eda_preprocessing.ipynb`, `02_ranker.ipynb` — исследование данных, предобработка, обучение и анализ модели.
- `tz.html` — техническое задание, `docs/model_report.html` — отчёт о качестве модели.
- `docs/project_guide.html` — гид по проекту для команды: пайплайн, источники, вопросы жюри и заказчиков, речь к `docs/преза.pptx` (тексты слайдов — `docs/presentation_texts.md`).

**Качество модели на тесте** (октябрь–декабрь 2025, 88 150 закупок, модель их не видела): реальный победитель первым в 37,7% закупок, в топ-10 — в 69,3%, медиана места — 3.

## Запуск

```sh
git lfs install && git lfs pull      # артефакты модели в models/
pip install -r requirements.txt      # в тот Python, которым запускается сервер
cd web-service
python server.py                     # http://127.0.0.1:8000
```

В Windows можно открыть `web-service/run.bat`. По умолчанию обработка CSV идёт в деморежиме; реальная модель в обработке CSV — `PIPELINE_MODE=live`. Эндпоинт `/api/recommendations` работает с реальной моделью в любом режиме. Модель грузится в фоне при старте (~6 с), дальше ~1–3 с на закупку.

## API модели: `POST /api/recommendations`

Одна новая закупка → топ поставщиков. Запрос только с того же адреса, что и интерфейс (`127.0.0.1:8000`).

Запрос (`Content-Type: application/json`):

```json
{
  "subject": "Поставка крупы гречневой для нужд ГБОУ школа № 1",
  "items": [{"name": "Крупа гречневая ядрица", "okpd2": "10.61.32.113"}],
  "start_price": 250000,
  "is_smp": false,
  "customer_inn": "7802141070",
  "customer_kpp": "780201001",
  "top_k": 10
}
```

| Поле | Обязательно | Описание |
|---|---|---|
| `subject` | да | предмет закупки, от 3 символов |
| `items` | нет | позиции ТРУ: `name`, `okpd2` (формат `XX.XX.XX.XXX`, можно короче) |
| `start_price` | нет | НМЦК, ₽ |
| `is_smp` | нет | закупка только у МСП, по умолчанию `false` |
| `customer_inn`, `customer_kpp` | нет | заказчик: 10 и 9 цифр |
| `top_k` | нет | 1–50, по умолчанию 10 |

Ответ `200`:

```json
{
  "model_version": "lgbm-lambdarank-2025-12-it499",
  "took_ms": 1840,
  "candidates_considered": 229,
  "lot": {"customer_known": true, "okpd2_recognized": 7},
  "warnings": [],
  "items": [
    {
      "rank": 1,
      "inn": "7806410527",
      "score": 100.0,
      "p_win": 0.2128,
      "fit": 81.4,
      "status": "Проверенный",
      "status_rule": "≥ 3 побед в группе ОКПД2 лота, последняя — не раньше 12 месяцев назад",
      "reasons": ["Предмет закупки похож на его прошлые контракты (сходство 0.68)",
                  "10 побед в этом классе ОКПД2 у заказчиков того же района",
                  "35 побед с точно таким же кодом ОКПД2"],
      "risks": ["Не работал с этим заказчиком"],
      "factors": [
        {"feature": "text_cos", "title": "Сходство текста лота с его прошлыми лотами", "group": "текст",
         "value": 0.6783, "contribution": 1.0196}
      ]
    }
  ]
}
```

- `score` — 0–100, место среди всех кандидатов лота (100 — лучший); `p_win` — вероятность победы 0–1 (делится между всеми кандидатами лота, поэтому у сильных, но не первых компаний мала); `fit` — «Соответствие» 0–100: оценка выше, чем у `fit`% реальных победителей (шкала `models/fit_calibration.json`, `scripts/calibrate_fit.py`).
- `factors` — до 8 признаков с наибольшим влиянием; `contribution > 0` повышает оценку, `< 0` понижает.
- `warnings` — например, заказчик не встречался в истории или коды ОКПД2 не переданы.
- Ошибки: `400 {"error": "текст"}` — неверные поля; `503` — модель не подключена; `500` — сбой модели.
- Название, роль и регион компании по ИНН — в API обогащения (`enrichment`, `GET /api/suppliers/{inn}`).

## Модель (`recsys/`)

```
textprep.py    очистка и лемматизация текста закупок
data.py        загрузка очищенных таблиц, словари, история участий
text.py        TF-IDF + SVD векторы лотов
profiles.py    профили поставщиков на срез (без утечки из будущего)
candidates.py  кандидаты: ОКПД2, заказчик, текст → RRF (до 300 на лот)
features.py    33 признака пары «лот × кандидат», монотонность
explain.py     причины из SHAP-вкладов и статус контрагента
metrics.py     Recall@K, MRR, NDCG
inference.py   Recommender: сырой лот → выдача с объяснениями
webservice.py  адаптер для web-service: recommend(), recommend_detailed(), warmup()
```

Обучение с нуля: положите CSV организаторов в корень, выполните `01_eda_preprocessing.ipynb` (~8 мин), затем `02_ranker.ipynb` (~1 ч, пик памяти ~10 ГБ). Сплит по времени: обучение — апрель–август 2025, калибровка — сентябрь, тест — октябрь–декабрь. Внешние API нейросетей не используются.
