# Подбор контрагентов для закупок СПб

Сервис для хакатона RLT: по извещению о закупке и её позициям ТРУ строит ранжированный список поставщиков с вероятностью победы, статусом и причинами рекомендации.

**Качество на тесте** (октябрь–декабрь 2025, 88 150 закупок, модель их не видела): реальный победитель первым в 37,7% закупок, в топ-10 — в 69,3%, медиана места — 3. Подробнее — в `docs/model_report.html`.

## Структура

```
recsys/                     пакет: общий код для обучения и сервиса
  textprep.py               очистка и лемматизация текста закупок
  data.py                   загрузка очищенных таблиц, словари, история участий
  text.py                   TF-IDF + SVD векторы лотов
  profiles.py               профили поставщиков на срез (без утечки из будущего)
  candidates.py             кандидаты: ОКПД2, заказчик, текст → RRF
  features.py               33 признака пары «лот × кандидат», монотонность
  explain.py                причины из SHAP-вкладов и статус контрагента
  metrics.py                Recall@K, MRR, NDCG
  inference.py              Recommender: сырой лот → выдача с объяснениями
01_eda_preprocessing.ipynb  исследование данных и предобработка → data/processed/
02_ranker.ipynb             кандидаты, признаки, обучение LightGBM, анализ → models/
models/                     артефакты модели (бинарные файлы — через Git LFS)
docs/model_report.html      отчёт о качестве модели для заказчика
tz.html                     техническое задание
enrichment/                 обогащение контрагентов по ИНН (ФНС, ЕИС, реестры) — см. docs/enrichment/README.md
```

## Установка

```bash
git lfs install          # до клонирования, чтобы скачались артефакты модели
git clone <repo-url>
pip install -r requirements.txt
```

## Инференс

Готовые артефакты лежат в `models/`, данные для инференса не нужны.

```python
from recsys.inference import Recommender

rec = Recommender('models')
rec.recommend({
    'subject': 'Поставка крупы гречневой для нужд ГБОУ школа № 1',
    'items': [{'name': 'Крупа гречневая ядрица', 'okpd2': '10.61.32.113'}],
    'start_price': 250000, 'is_smp': False, 'platform': 'EM',   # EM — Электронный магазин, AISGZ — АИС ГЗ
    'customer_inn': '7802141070', 'customer_kpp': '780201001',
}, top_n=20)
```

Ответ: `rank`, `inn`, `score`, `p_win` (вероятность победы), `status`, `status_rule`, `reasons`, `risks`.

## Обучение с нуля

1. Положите в корень проекта CSV организаторов: `Извещения_24-25.csv`, `ТРУ_24-25.csv`, `Поставщики_24-25.csv`.
2. Выполните `01_eda_preprocessing.ipynb` (~8 мин) → `data/processed/`.
3. Выполните `02_ranker.ipynb` (~1 ч, пик памяти ~10 ГБ) → `data/features/`, `models/`.

Сплит по времени: обучение — апрель–август 2025, ранняя остановка и калибровка — сентябрь, тест — октябрь–декабрь. Профили поставщиков для лота месяца M считаются по истории строго до начала месяца M.

Внешние API нейросетей не используются: текстовая модель и ранкер работают локально.
