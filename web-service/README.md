# Undefined squad — локальный MVP подбора поставщиков

Ваша часть хакатона: рабочий интерфейс, приём двух CSV, проверка данных, фоновая обработка, просмотр результата и скачивание `Поставщики.csv`.

**Сейчас включён деморежим.** Компании и оценки вымышлены, ИНН пустые, источники не запрашиваются. Деморежим проверяет интеграционный сценарий, не качество подбора. Ограничение организаторов на внешние API нейросетей учтено: приложение их не использует. Примеры тоже синтетические.

## Быстрый запуск

Нужен Python 3.10 или новее. Сторонних пакетов нет, установка зависимостей не требуется.

Windows: дважды нажмите `run.bat`, оставьте окно сервера открытым и откройте http://127.0.0.1:8000.

Или из папки проекта:

```powershell
py -3 server.py
```

Linux/macOS:

```sh
python3 server.py
```

Порт занят: `py -3 server.py --port 8001`, адрес http://127.0.0.1:8001. Остановка запущенного в терминале сервера: Ctrl+C. Перезапуск — той же командой.

## Сценарий демонстрации

1. Нажмите «Загрузить CSV-файлы» и выберите сразу «Извещения» и «ТРУ» либо перетащите оба файла в общую область. Для демонстрации можно нажать «Подставить пример».
2. Нажмите «Сформировать „Поставщики“».
3. После обработки появятся сводка, таблица, карточки с причинами и кнопка «Скачать CSV».
4. На примерах: 3 лота, 5 позиций ТРУ, 9 демонстрационных рекомендаций (при top_k ≥ 3).

Демо возвращает максимум 3 вымышленные компании на лот независимо от большего top_k. В файл входят `is_demo=True` и явные отметки демо. Реальный режим никогда не подменяет ошибку модели демоданными.

## Входные файлы

| Файл | Обязательные столбцы |
|---|---|
| Извещения | `lot_id`, `subject` (либо `procedure_name`) |
| ТРУ | `lot_id`, `product_name`, `okpd2_code` |

Остальные поля извещения, например `start_price`, `is_smp`, `customer_inn`, `publish_date`, передаются модели без потери. Значения остаются строками, в том числе ИНН и идентификаторы с ведущими нулями. Пустой `okpd2_code` допустим: команда модели может определить его по тексту.

Поддержка UTF-8/BOM и Windows-1251, разделитель `;` или `,`. В CSV должна быть строка заголовков. При наличии разделителей/переносов внутри значения используйте стандартное CSV-экранирование кавычками.

Интерфейс определяет тип файла по столбцам: порядок выбора и названия файлов не важны. Можно добавить файлы по очереди, заменить один или убрать его. Два файла одного типа и выбор более двух файлов отклоняются с пояснением.

- Дубликат `lot_id` в извещениях — ошибка: для этого MVP один лот соответствует одному извещению.
- ТРУ с неизвестным `lot_id` — ошибка, нужно загрузить согласованную пару файлов.
- Извещения без ТРУ пропускаются с предупреждением.
- Пустые файлы, пропущенные заголовки и строки неправильной ширины отклоняются.
- Позиция без названия принимается, если указан ОКПД2. Строки ТРУ без названия и кода пропускаются, их количество явно показывается в предупреждении.
- Максимум 512 МБ на файл по умолчанию. `MAX_FILE_MB` меняет лимит перед запуском.

Исходный исторический датасет «Поставщики» из ТЗ нужен обучению/индексу команды ML. Он **не загружается заказчиком** и не равен выходному файлу рекомендаций. Выходной файл не содержит `is_winner`: прогноз не является фактом победы.

## Подключение команды

Согласованный интерфейс описан в [INTEGRATION.md](INTEGRATION.md).

- `integrations/recommender.py` — локальная модель и исторический индекс поставщиков.
- `integrations/enricher.py` — поиск новых компаний и обогащение.
- `models.py` — общие структуры `Lot` и `Candidate`.

Замените две функции, установите оба `READY = True`, перезапустите сервер в рабочем режиме:

```powershell
$env:PIPELINE_MODE = 'live'
py -3 server.py
```

Если адаптеры не готовы, сервер не позволит запустить рабочий подбор. Переменные из `.env` автоматически не загружаются.

## Структура

```text
server.py              локальный HTTP API и фоновые задачи
pipeline.py            CSV → проверка → SQLite → модель → обогащение → CSV
models.py              контракт данных
integrations/          два места подключения командных модулей
web/                   интерфейс: HTML, CSS, JavaScript
examples/              два синтетических входных CSV
tests/                 проверки CSV, интеграций и API
data/<job_id>/          входные файлы, SQLite, статус и результат
```

На текущем этапе использованы стандартная библиотека Python, SQLite и JavaScript без сборки. Это сознательное упрощение вашего текущего MVP относительно чернового ТЗ с React/FastAPI/PostgreSQL: запуск не требует npm, pip или Docker. Модель можно импортировать напрямую как Python-модуль. Полный функциональный объём ТЗ не реализован: обучение, поиск по реестрам, бизнес-фильтры, метрики качества и production-развёртывание остаются отдельными задачами.

## Хранение и ограничения

Сервер слушает только `127.0.0.1`, рассчитан на локальный стенд. Есть проверка Host/Origin, но нет учётных записей; для публичного развёртывания нужен отдельный сервер приложения и контроль доступа. Не выставляйте этот HTTP-сервер в интернет.

Загрузка идёт частями на диск; CSV читаются построчно, соединение таблиц выполняется в SQLite. В памяти находятся текущий лот, его кандидаты и до 100 строк предпросмотра. Браузер получает максимум 100 строк, CSV содержит полный результат.

Одна задача обработки одновременно; параллельный запуск возвращает понятную ошибку. Это последовательная обработка лотов для MVP, не обещание скорости на полном наборе в 3 млн позиций. Проверка полной загруженной пары прошла: 604 452 извещения, 2 971 651 исходная строка ТРУ, 604 435 лотов с пригодными позициями. Пропущены с предупреждением 113 пустых строк ТРУ и 17 извещений без пригодных позиций. Полный расчёт рекомендаций и время обработки реальной моделью не измерены. Для демонстрации используйте согласованный срез лотов и ТРУ.

Статусы и завершённые результаты сохраняются после перезапуска. Незавершённая обработка помечается прерванной, её надо запустить заново. Страница восстанавливает последнюю запущенную задачу в этом браузере. После смены компьютера/браузера история автоматически не переносится. Автоудаления данных нет; остановив сервер, ненужные папки задач в `data/` можно удалить. `DATA_DIR` позволяет выбрать другое место хранения.

Для CSV используется UTF-8 BOM и `;`, потенциальные формулы обезвреживаются. Excel может сам преобразовывать длинные числовые идентификаторы: импортируйте столбцы `lot_id`, `supplier_inn`, `supplier_kpp` как текст, чтобы сохранить ведущие нули.

## Проверки

```powershell
py -3 -m unittest discover -s tests -v
node --test tests/file-selection.test.cjs
```

Для тестов выбора файлов нужен Node.js 20 или новее; для самого сервиса Node.js не требуется. Тесты используют временные каталоги и временный локальный порт, не меняют пользовательские загрузки.
