# Вызов модели через POST /analyze

Endpoint сервиса: `http://127.0.0.1:8000/analyze`. Также доступен `/api/analyze`.

Принимает непустой JSON-объект и отправляет его POST-запросом в отдельно запущенный сервис модели. Названия полей, вложенность, типы и порядок результатов сохраняются. Ответ модели (JSON-объект или массив) возвращается клиенту. Обогащение не вызывается, демонстрационные поставщики не подставляются.

## Подключение

Задайте фактический адрес endpoint модели в переменной `MODEL_ANALYZE_URL` перед запуском веб-сервера. Например, **если модель действительно принимает POST /predict на порту 8001**:

```powershell
$env:MODEL_ANALYZE_URL = 'http://127.0.0.1:8001/predict'
$env:MODEL_ANALYZE_TIMEOUT = '60'
py -3 server.py
```

Адрес модели должен отличаться от адреса веб-сервера. Если модель работает на другом компьютере команды, укажите его адрес в локальной сети. Таймаут по умолчанию 60 секунд, допустимо до 300. Переменные из `.env` автоматически не читаются.

## Запрос

Заголовок: `Content-Type: application/json`. Максимальный размер тела — 1 МБ. Ниже пример полей, а не утверждённая схема модели; замените их на входной контракт сокомандника:

```json
{
  "lot_id": "0001",
  "subject": "Поставка бумаги",
  "items": [
    {"product_name": "Бумага А4", "okpd2_code": "17.12"}
  ],
  "top_k": 10
}
```

Сохраните согласованный JSON в `request.json` и выполните:

```powershell
curl.exe http://127.0.0.1:8000/analyze -H "Content-Type: application/json" --data-binary "@request.json"
```

Количество и ранжирование поставщиков определяет модель. Endpoint не добавляет `top_k` автоматически и не меняет шкалу оценок.

## Статусы

| HTTP | Значение |
|---|---|
| 200 | Получен ответ модели |
| 400 | Некорректный или пустой JSON |
| 403 | Запрос не с локального адреса сервиса |
| 408 | Не удалось вовремя прочитать тело запроса |
| 413 | Запрос превышает 1 МБ |
| 415 | Нужен Content-Type application/json |
| 502 | Ошибка подключения, HTTP-ошибка модели или некорректный ответ |
| 503 | Адрес модели не настроен или конфигурация некорректна |
| 504 | Истекло время ожидания модели |

Ответы модели ограничены 4 МБ. Переадресации не выполняются. `GET /api/health` содержит `analyze_configured`: это наличие адреса в настройках, а не проверка доступности модели.

## CSV и PostgreSQL

Этот endpoint принимает уже подготовленные поля. Он не читает PostgreSQL и не преобразует загруженные CSV автоматически. Существующая загрузка CSV пока использует прежнюю цепочку `/api/jobs`. Для её подключения к реальной модели нужно согласовать входные поля и формат топ-10, затем связать преобразование лота и вывод результата с этой моделью. Для доступа к PostgreSQL также нужны схема таблиц и параметры подключения.
