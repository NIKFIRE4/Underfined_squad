# Регрессия CSV и экспорта на pytest

Запуск из `web-service` в окружении с зависимостями проекта:

```powershell
python -m pip install -r requirements-test.txt
python -m pytest tests/test_csv_export_regression.py -v
```

## Область проверки

| Требование | Проверки |
| --- | --- |
| IMP-01 | UTF-8, UTF-8 BOM и CP1251 с двумя разделителями; кириллица, кавычки, многострочный текст, ведущие нули |
| IMP-02 | Повторные, пустые и совпадающие после нормализации заголовки |
| IMP-03 | Пустой идентификатор/предмет, лишние и недостающие значения |
| IMP-04 | Двухбайтовый UTF-8 символ на границе выборки определения кодировки 64 KiB |
| EXP-01 | Все 151 строка одного лота в CSV/XLSX, исключение другого лота, сохранение ИНН/КПП и специальных символов |
| EXP-02 | Заголовки в выгрузке известного лота без кандидатов |
| EXP-03 | Длина ячейки XLSX: 32766, 32767, 32768 символов |
| EXP-04 | Значения, похожие на формулы, сохраняются в XLSX как текст |

Это модульные проверки парсера и проверки чтения сохранённого результата с формированием выгрузки. XLSX читается независимой библиотекой openpyxl. Тесты не проверяют UI, HTTP-маршруты, реальную PostgreSQL, точность модели или внешнее обогащение. Существующие unittest-проверки API и обработки закупок остаются отдельным набором.

Фикстуры создают синтетические файлы в уникальном временном каталоге и удаляют их после каждого теста, включая неуспешный. Набор не подключается к рабочей БД и не запускает подбор моделью. Параметры дают 25 отдельных проверок; это число примеров, а не процент покрытия кода или требований продукта.
